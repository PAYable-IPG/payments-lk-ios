# Changelog

## 0.1.2 (30 September 2026)

Also on CocoaPods. The code is the same as 0.1.1.

- Add `pod 'PaymentsLk', '~> 0.1'` to your Podfile, for an app that still uses CocoaPods. CocoaPods stops taking new versions on 2 December 2026, so Swift Package Manager stays the way to get every version after that.

## 0.1.1 (29 September 2026)

The first version from its own repository, https://github.com/PAYable-IPG/payments-lk-ios. The code is the same as 0.1.0.

- Add it with Swift Package Manager from that address instead of a downloaded folder.

## 0.1.0 (15 September 2026)

The first version: `PaymentsLkCheckout.present` opens a hosted checkout in `ASWebAuthenticationSession` and answers a `CheckoutResult` from the return to your app.
