# Contributing

Thank you for helping. This repository is where PaymentsLk is released from. It is written and tested in the Payments.lk monorepo, and each release replaces what is here with the monorepo's copy. The monorepo also runs the tests that check this SDK against the API's own contracts, which is why a few tests are not in this repository.

- **Found a bug or want something added?** Open an issue here.
- **Have a fix?** Open a pull request. We carry it over to the monorepo, credit you in the commit, and it ships in the next release. A change merged only here would be overwritten by that release.
- **Found a security problem?** Please do not open an issue. SECURITY.md says how to tell us privately.

The API this SDK calls is documented at https://payments.lk/developers, and what changed in each version is in CHANGELOG.md.
